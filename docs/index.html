04 / Get started

From clone to
quiet confidence.

Bring your own Telegram credentials and groups. Add Twilio only if urgent calls are worth the small usage cost to you.

  1. 01
    Install

    Run the PowerShell setup to create an isolated Python environment.

  2. 02
    Connect Telegram

    Add personal API credentials and create a private BotFather alert bot.

  3. 03
    Choose sources

    Join groups yourself, review their quality, and add only their local chat IDs.

  4. 04
    Test safely

    Use doctor, sample scoring, and dry-run mode before enabling any notifications.

  5. 05
    Stay ready

    Install the Windows sign-in task; optionally enable HIGH-alert calls.
